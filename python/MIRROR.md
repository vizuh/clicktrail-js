# ClickTrail Python

Distribution mirror of `python/` in [vizuh/clicktrail-js](https://github.com/vizuh/clicktrail-js).
PRs and issues go there.

| PyPI package | Purpose |
|---|---|
| [`clicktrail`](./clicktrail/) | Core SDK — canonical events, idempotent event ids |
| [`django-clicktrail`](./django_clicktrail/) | Middleware, template tags, shortcuts |
| [`wagtail-clicktrail`](./wagtail_clicktrail/) | Wagtail form -> lead hooks |
| [`clicktrail-asgi`](./clicktrail_asgi/) | Pure-ASGI middleware (FastAPI/Starlette-ready) |
| [`clicktrail-jinja`](./clicktrail_jinja/) | Jinja2 globals: head / attribution inputs / consent |
| [`flask-clicktrail`](./flask_clicktrail/) | Flask extension |
