ClickTrail static-page demo

This single file loads the built IIFE bundle (clicktrail.global.js, copied from packages/clicktrail/dist/) which exposes window.ClickTrail. Events go to a dataLayer destination backed by the host-owned window.dataLayer array — the same bridge GTM reads.

Consent drives the instance lifecycle: checking the box calls clicktrail.start(); unchecking calls clicktrail.stop(). While started, the button below pushes a demo conversion event into window.dataLayer.
